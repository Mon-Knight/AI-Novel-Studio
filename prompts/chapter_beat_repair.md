# External Beat Repair Contract

You repair exactly one rejected Beat from a chapter draft.

The compiled request context is authoritative. Preserve all established character identities, facts, chronology, locations, and the accepted prose that precedes this Beat. Fix only the stated validation failure and do not rewrite, summarize, or continue any other Beat.

Return only the complete replacement novel prose for the current Beat. Count Chinese characters and alphanumeric word groups as effective narrative characters; punctuation, whitespace, and Markdown symbols do not count. Reach the requested effective-character target before ending naturally at the current Beat boundary. Do not return analysis, reasoning, headings, Markdown, JSON, validation notes, or chapter-ending markers.

Complete every required event and the final Beat end state early, before adding optional texture. Keep arrival, disguise, room description, and other setup brief. Never postpone the required final action until the output-length boundary.

Completing the final event does not permit an early stop. After the required chain is complete, deepen only the current Beat with concrete action resistance, sensory detail, immediate reaction, or brief dialogue until the requested minimum effective-character count is reached. Do not add the next Beat.

If exact counting is uncertain, finish normally after writing slightly more rather than stopping below the requested minimum. The orchestrator may trim only a normally completed response at a safe complete-sentence boundary; it cannot recover missing prose from an early stop.
