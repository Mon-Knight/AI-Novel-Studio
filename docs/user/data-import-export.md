# 数据导入导出说明

> 当前状态：✅ v1.7.8 已补充  
> 适用版本：v1.7.8+

---

## 1. 功能定位

导入导出用于把作品内容从 AI Novel Studio 中安全带出，或把外部文本导入到当前创作流程中。

导出动作不会修改作品数据，只会生成用户选择位置的文件。

---

## 2. 当前支持的格式

| 功能 | 格式 | 说明 |
|------|------|------|
| TXT 导入 | `.txt` | 导入纯文本内容 |
| Markdown 导入 | `.md` / `.markdown` | 导入 Markdown 内容 |
| 章节导出 | `.txt` | 导出单章正文 |
| 章节导出 | `.md` | 导出单章 Markdown |
| 整本导出 | `.txt` | 按章节顺序导出整本作品 |
| 整本导出 | `.md` | 按章节结构导出整本作品 |
| 项目备份 | `.json` | 导出作品基础数据备份 |

---

## 3. 保存位置选择

桌面模式下，导出会调用 Tauri 保存对话框：

1. 用户点击导出按钮。
2. 系统弹出保存文件对话框。
3. 用户选择文件名和保存位置。
4. 系统写入文件。
5. 页面展示导出成功和保存路径。

浏览器开发模式下，如果 Tauri API 不可用，会回退到浏览器下载方式。

---

## 4. 常用入口

| 入口 | 说明 |
|------|------|
| `/import-export` | 集中导入导出页面 |
| 作品卡片导出入口 | 快速导出当前作品 |
| 章节相关导出入口 | 导出当前章节内容 |

---

## 5. 编码与内容

- 导出文件使用 UTF-8。
- Markdown 导出保留标题结构。
- TXT 导出适合纯文本阅读和二次编辑。
- JSON 备份用于本地留档，不作为跨版本迁移协议的长期承诺。

---

## 6. 当前限制

- 批量导入导出指南尚未细化。
- JSON 备份恢复流程尚未完整开放。
- 导入格式校验仍较基础。
- 参考小说导入不属于当前版本范围。

---

