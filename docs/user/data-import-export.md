# 数据导入导出说明

> 当前状态：v3.6.0；完整项目备份当前为 schema 11<br>
> 适用版本：v2.1.2+（完整备份与恢复仅限桌面 SQLite；当前导出 schema 11）

---

## 1. 功能定位

导入导出用于把作品内容从 AI Novel Studio 中安全带出，或把外部文本导入到当前创作流程中。

导出动作不会修改作品数据，只会生成用户选择位置的文件。

---

## 2. 当前支持的格式

| 功能               | 格式                | 说明                                    |
| ------------------ | ------------------- | --------------------------------------- |
| TXT 导入           | `.txt`              | 导入纯文本内容                          |
| Markdown 导入      | `.md` / `.markdown` | 导入 Markdown 内容                      |
| 章节导出           | `.txt`              | 导出单章正文                            |
| 章节导出           | `.md`               | 导出单章 Markdown                       |
| 整本导出           | `.txt`              | 按章节顺序导出整本作品                  |
| 整本导出           | `.md`               | 按章节结构导出整本作品                  |
| 项目完整备份       | `.json`             | 导出版本化完整项目备份（仅桌面 SQLite） |
| 旧版项目 JSON 导入 | `.json`             | 仅导入基础作品资料，不能作为完整恢复    |

---

## 3. 保存位置选择

桌面模式下，导出会调用 Tauri 保存对话框：

1. 用户点击导出按钮。
2. 系统弹出保存文件对话框。
3. 用户选择文件名和保存位置。
4. 系统写入文件。
5. 页面展示导出成功和保存路径。

浏览器开发模式下，普通文本导出会回退到浏览器下载方式。完整项目备份与恢复依赖桌面 SQLite，不会在浏览器开发模式中声明为灾备能力。

---

## 4. 常用入口

| 入口             | 说明             |
| ---------------- | ---------------- |
| `/import-export` | 集中导入导出页面 |
| 作品卡片导出入口 | 快速导出当前作品 |
| 章节相关导出入口 | 导出当前章节内容 |

---

## 5. 编码与内容

- 导出文件使用 UTF-8。
- Markdown 导出保留标题结构。
- TXT 导出适合纯文本阅读和二次编辑。
- 完整项目备份使用独立的 `schemaVersion` 协议；当前导出为 schema 11，覆盖卷章、草稿、设定、上下文、大纲、生成与质量记录、故事资产、任务对话、产物决定和审阅授权，以及相关大文本数据。导入继续兼容 schema 2～10 的历史表集合。
- 必要的项目级 LocalStorage 缓存会作为补充数据写入完整备份；应用设置、API Key 和本机绝对路径不会导出。
- 旧版项目 JSON 仍可用于基础作品导入，但不具备完整恢复语义。

## 6. 完整项目备份与恢复

完整备份恢复始终导入为一个新作品，不覆盖现有作品。SQLite 中的导入、关联 ID 重写、外键检查和大文本完整性检查在同一事务中完成；任一步失败都会回滚该次 SQLite 写入。

项目级 LocalStorage 与 SQLite 是两个独立存储层，无法组成跨存储 ACID 事务。SQLite 恢复成功后，如果补充本地缓存恢复失败，前端会撤销刚导入的 SQLite 作品；若撤销也失败，应用会明确报告失败，不会将本次操作显示为恢复成功。

---

## 7. 当前限制

- 批量导入导出指南尚未细化。
- 完整备份与恢复仅支持桌面 SQLite 环境；当前可导入整数 `schemaVersion` 2～11，更旧、未来版本或非整数版本会被拒绝。
- 完整恢复不支持原位覆盖既有作品；恢复结果会作为新作品出现。
- SQLite 与 LocalStorage 尚未具备统一 ACID 事务或单一事实源。
- 普通文本与旧版 JSON 导入的格式校验仍较基础。
- 参考小说导入不属于当前版本范围。

---

## 8. 验证建议

```powershell
npm run build
```

在桌面模式下可手动验证：

```powershell
npm run tauri dev
```

然后尝试导出 TXT、Markdown 和完整项目 JSON 备份，确认保存对话框、保存路径提示和文件内容正常。导入完整备份后，确认原作品未被覆盖，并出现可独立打开的新作品。
