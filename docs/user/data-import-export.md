# 数据导入导出说明

> 当前状态：✅ 项目备份 schema v2
> 适用版本：v2.2.0+

---

## 1. 功能定位

导入导出用于把作品内容从 AI Novel Studio 中安全带出，或把外部文本导入到当前创作流程中。

导出动作不会修改作品数据，只会生成用户选择位置的文件。

---

## 2. 当前支持的格式

| 功能 | 格式 | 说明 |
|------|------|------|
| TXT 作品导入 | `.txt` | 自动切分章节，创建并采用正文版本 |
| JSON 项目恢复 | `.json` | 恢复作品、分卷、章节、已采用正文及作品级方案 |
| JSON 方案导入 | `.json` | 导入风格方案或输出控制方案 |
| 章节导出 | `.txt` | 导出单章正文 |
| 章节导出 | `.md` | 导出单章 Markdown |
| 整本导出 | `.txt` | 按章节顺序导出整本作品 |
| 整本导出 | `.md` | 按章节结构导出整本作品 |
| 项目备份 | `.json` | 导出 schema v2 项目备份，包含已采用正文 |

---

## 3. 保存位置选择

桌面模式下，导出会调用 Tauri 保存对话框：

1. 用户点击导出按钮。
2. 系统弹出保存文件对话框。
3. 用户选择文件名和保存位置。
4. 系统写入文件。
5. 页面展示导出成功和保存路径。

如果用户取消保存对话框，页面会显示“已取消导出”，不会误报导出失败。

浏览器开发模式下，如果 Tauri API 不可用，会回退到浏览器下载方式。

---

## 4. 导入文件选择与确认

桌面模式下，TXT 和 JSON 导入统一使用 Tauri 系统文件选择窗口：

1. 点击“选择文件”，在系统窗口中选择 `.txt` 或 `.json` 文件。
2. 选择后先核对文件名、完整路径和“等待解析”状态，此时不会写入任何数据。
3. 点击“解析并预览”，系统读取文件并校验格式。
4. TXT 预览显示章节切分、字数和警告；JSON 预览显示导入类型、名称和摘要。
5. 只有点击“确认导入”后才正式创建作品或方案。

取消系统文件窗口不会报错，也不会读取文件。重新选择会清除旧预览、错误和解析状态。解析失败时不会开始正式导入；导入按钮带有防重复提交保护。

项目导入中途失败时，桌面端会在 SQLite 事务中清理本次新建的作品、分卷、章节、正文草稿和关联导入数据，已有作品不受影响。

---

## 5. 常用入口

| 入口 | 说明 |
|------|------|
| `/import-export` | 集中导入导出页面 |
| 作品卡片导出入口 | 快速导出当前作品 |
| 章节相关导出入口 | 导出当前章节内容 |

---

## 6. 编码与内容

- 导出文件使用 UTF-8。
- Markdown 导出保留标题结构。
- TXT 导出适合纯文本阅读和二次编辑。
- TXT/Markdown 只导出实际存在已采用正文版本的章节，不依赖可能滞后的章节状态字段。
- JSON schema v2 为每章保存已采用正文；恢复时重新生成本地 ID，并保持分卷与章节关联。
- 如果已采用正文的完整内容暂时不可读取，导出会停止，不会生成截断文件。
- JSON 备份用于本地留档，不作为任意未来版本之间的永久迁移协议。

---

## 7. 当前限制

- 批量导入导出指南尚未细化。
- 世界设定、规则、角色、摘要和上下文会保留在备份文件中，但当前自动恢复仅覆盖作品、分卷、章节正文、风格方案和输出控制方案。
- schema v1 等旧备份如果不含章节正文，只能恢复章节结构；界面会明确提示缺失正文的章节数。
- JSON 导入格式校验仍以现有字段兼容为主，不接受任意 JSON 数据。
- 参考小说导入不属于当前版本范围。

---

## 8. 验证建议

```powershell
npm run build
```

在桌面模式下可手动验证：

```powershell
npm run tauri dev
```

然后尝试：

- 取消 TXT / JSON 文件选择，确认页面不报错；
- 选择文件后核对路径和解析状态；
- 查看预览后确认导入；
- 导出 TXT、Markdown 和 JSON 备份，确认保存对话框、保存路径提示和文件内容正常。
