# Windows 桌面端使用说明

> 基线：v3.7.0。默认入口是创作工作台，不是作品管理首页。

## 启动

1. 安装后双击 `AI Novel Studio.exe`，或开发时运行 `npm run tauri:dev`。
2. 首次启动先看到稳定骨架，任务与作品在后台恢复。
3. 浏览器开发模式（`npm run dev`）用于界面调试，不能代替桌面 SQLite / DSH 验收。

## 窗口

- 主窗口无系统标题栏：顶部标签栏可拖动，双击最大化。
- 右侧自绘最小化 / 最大化（还原） / 关闭；关闭会走既有离开保护（未保存正文先询问）。
- 浏览器模式不显示窗口控制按钮。
- 参考尺寸：默认约 1280 × 820，最小约 1024 × 700，可最大化；2K 下侧栏与面板按令牌加宽，不做移动优先布局。

## 壳层导航

| 区域     | 作用                                                                           |
| -------- | ------------------------------------------------------------------------------ |
| 顶部标签 | 会话 / 项目 / 当前页面；收起侧栏；版本与资源中心入口                           |
| 侧栏快捷 | 新建任务 `Ctrl+N`、搜索 `Ctrl+K`、自主创作、项目库                             |
| 分组导航 | 工作区（会话 / 项目 / 资源中心）；进入作品后追加「当前项目」页                 |
| 资源中心 | 风格方案、模板中心、创作资产、导入导出、AI 任务记录，以及按 `?tab=` 分类的设置 |

当前项目页通常包括：作品概览、章节审阅、大纲、设定推演、参考资料、故事资产、自主创作。

## 创作工作台（默认 `/`）

- 左侧是项目 / 任务树：标题、相对时间、状态色点。
- 中间是对话流：用户气泡、运行块、产物卡。
- 底部输入为悬浮卡片：左侧上下文，右侧模型与发送。
- 右侧可打开创作上下文、本任务产物、运行日志、当前插件、章节审阅或作品概览，不是旧的多块 AI 面板。
- 发送前模型必须出现在当前 Runtime 目录；桌面 DSH 任务还会做可取消的 tool-call 探针。

## 写作工作台（章节审阅）

从作品进入「章节审阅」，或从产物卡片转入。

- **左侧**：卷章目录树。
- **中间**：正文纸张，可显式编辑。
- **右侧工具轨**：保存、草稿、准备、总结、排版、采用。

这里**没有**右侧 AI 生成控制面板。生成、润色类请求在创作工作台以任务发出。

## 数据与安全

- 桌面权威数据在本机 SQLite；浏览器开发用 LocalStorage 回退，不能冒充桌面事务。
- API Key 在 Windows 上用 DPAPI 保存，不进入项目备份、日志或 Git。
- 完整项目备份 / 恢复在导入导出中心；恢复创建新作品，不覆盖现有作品。
- 「删除作品」在桌面端是级联清除该作品持久事实；「扫描并修复数据库」扫描 SQLite 作品字段，不是浏览器镜像。

- 参考导入以 TXT 为主。
