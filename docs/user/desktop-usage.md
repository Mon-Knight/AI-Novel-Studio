# Windows 桌面端使用说明

> AI Novel Studio 桌面端操作指南

## 启动桌面应用

1. 双击 `AI Novel Studio.exe` 启动应用
2. 或通过命令行：`npm run tauri dev`

## 窗口控制

- **默认窗口**：1280 × 820
- **最小窗口**：1024 × 700
- **可最大化**：支持窗口最大化，UI 自适应
- **可调整大小**：支持自由拖拽调整窗口大小

## 页面导航

左侧导航栏提供以下入口：

| 导航项      | 页面             | 说明                       |
| ----------- | ---------------- | -------------------------- |
| 小说作品    | `/`              | 作品管理首页               |
| 创作资产    | `/assets`        | 角色、势力、地点、规则管理 |
| 风格方案    | `/styles`        | 风格方案与输出控制方案     |
| 模板中心    | `/templates`     | 提示词模板管理             |
| AI 任务记录 | `/ai-tasks`      | AI 任务历史记录            |
| 导入导出    | `/import-export` | TXT/Markdown 导入导出      |
| 设置中心    | `/settings`      | AI 设置与 Mock 模式        |

## 写作工作台

从作品卡片点击"进入工作台"或从作品详情页进入。

写作工作台布局：

- **左侧**：卷章目录树
- **中间**：正文编辑区
- **右侧**：AI 生成控制面板

## 数据存储

- 所有数据保存在本地（浏览器模式用 LocalStorage，桌面模式用 SQLite）
- API Key 仅本地加密存储
- 导出文件由用户选择保存位置

## 当前限制

- 文档基线：v1.7.11（当前应用版本见 `../version-roadmap.md`）
- 部分高级功能（分卷大纲生成、章节大纲生成等）在后续版本开放
- 详见 [版本路线图](../project/version-roadmap.md)
