# 创作工作流指南

> 基线：v3.7.0。本文描述当前默认主路径，不表示未列出的页面已删除。

推荐顺序：

```text
创建作品与基础设定
→ 创作工作台建立任务并生成候选
→ 写作工作台审阅、编辑、保存、采用
→ 章节总结沉淀上下文
→ 继续下一章
```

## 1. 准备作品

1. 从侧栏「项目库」或作品概览新建小说。
2. 在作品详情填写世界背景、规则体系和主角设定。
3. 建立分卷与章节，至少写好本章大纲和目标字数。
4. 需要时在角色库、风格方案、参考资料中补资产。空白项目也可以先在工作台发送创作目标，按提示生成待确认的设定与规划候选。

## 2. 在创作工作台生成候选

1. 打开应用后默认进入「创作工作台」（`/`）。
2. 选择小说项目，用「新建任务」或输入区发送目标，例如「生成下一章」。
3. 绑定目标章节与当前 Runtime 目录中的模型后发送。
4. 对话里查看工具调用、错误和产物卡片。候选不会自动写成正式正文。
5. 桌面端使用真实 API 模型时，写章默认由 Writing SubAgent 读取上下文并提交一份候选；Mock 与本地模型走确定性写章管线。需要关闭 SubAgent 时，见 [用户指南第 8 节](../user-guide.md)。
6. 结构化产物（大纲、角色、事件、设定、章节总结）须在卡片上显式「应用到作品」；章节正文须确认进入审阅。

## 3. 在写作工作台审阅与采用

1. 从产物卡片或项目页进入「章节审阅」。
2. 阅读候选，可显式进入编辑、保存草稿。
3. 确认无误后点击「采用」。采用在同一事务中切换正式正文，并失效过期的旧章节上下文。
4. 右侧工具轨提供保存、草稿历史、章节准备、总结、排版和采用。这里没有独立的 AI 生成面板；生成入口在创作工作台。

## 4. 沉淀后再写下一章

1. 采用后使用「总结」生成章节上下文，检查后确认。
2. 回到创作工作台继续下一章，或发送「继续写」。
3. 已采用正文会进入长期 Memory，供后续检索；未采用候选不会污染正式事实。

## 5. 并行入口（不是默认主路径）

下列页面仍然可用，用于全书规划或资产推演，**不替代**工作台任务对话：

- **自主创作**：全书计划与候选队列，正式采用仍要回到章节审阅。
- **设定推演**：角色 / 势力 / 地点 / 规则候选，须用户采纳后才写入正式资产。
- **大纲页**：人工维护全书 / 分卷 / 章节大纲。
- **AI 任务记录**：只读历史，不是新的生成入口。

## 当前限制

- R4 live 云端只读验收尚未完成，不能把 Mock 或仓内 loopback 当成完整自主 Agent。
- 参考资料目前以 TXT 为主；EPUB / PDF 未开放。
- 质量检查与润色仍按既有章节工具进行，结果保存为新草稿或报告，不自动覆盖采用稿。
