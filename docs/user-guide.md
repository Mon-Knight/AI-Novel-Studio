# AI Novel Studio 用户指南

## 1. 创建作品

1. 打开首页，点击「新建作品」
2. 填写作品名称（必填）、题材、简介
3. 点击确认创建

## 2. 填写世界背景

在作品详情页：

1. 点击「世界背景」卡片的编辑按钮
2. 输入大致世界观描述，不需要一次性写完
3. 后续 AI 会根据这些内容辅助整理结构化设定

## 3. 设定规则体系

1. 点击「规则体系」卡片的新增规则
2. 填写规则标题和内容（如魔法系统、科技设定、战斗规则）
3. 可添加多条规则，正文生成时 AI 必须遵守

## 4. 设定主角

1. 点击「主角设定」卡片的编辑
2. 填写主角姓名、性格、目标
3. 填写特殊能力与能力限制
4. 填写禁止行为（AI 生成时不会让主角做出这些行为）

## 5. 创建分卷与章节

1. 点击「大纲与章节管理」的新建分卷
2. 填写分卷标题和目标
3. 点击分卷下的新建章节
4. 填写章节标题、大纲和目标字数

## 6. 配置 AI

1. 打开设置中心
2. 使用 Mock 模式进行无 API Key 测试
3. 或关闭 Mock 模式，填写 API Base URL、API Key、模型名称

## 7. 使用 Mock 模式

Mock 模式可以让你在不消耗 API 额度的情况下测试完整工作流：

- AI 正文生成：返回模拟章节正文
- 角色生成：返回预设候选角色
- 事件建议：返回建议事件
- 章节总结：生成模拟总结
- 质量检查：返回模拟问题报告
- 正文润色：返回简单润色版本

## 8. 生成章节正文

1. 在设置中心配置模型（或先用 Mock 模式）
2. 打开默认首页「创作工作台」，选择小说项目
3. 在任务顶部选择目标章节；没有章节时先到「小说作品」创建分卷和章节
4. 发送「生成下一章」或点击快捷模板
5. 等待写章管线完成，对话中会出现候选产物卡片
6. 确认进入审阅后，在写作工作台修改并保存

## 9. 保存草稿与确认采用

1. 工作台生成的是候选，不会直接写成正式正文
2. 在写作工作台可以直接修改正文
3. 点击「保存草稿」保存当前版本
4. 在草稿历史面板中点击「采用」确认正式正文
5. 已采用的正文会更新章节字数，并写入长期 Memory 供后续检索

## 10. 生成章节总结

1. 确认采用草稿后，页面顶部会出现「生成章节总结」按钮
2. 点击按钮，AI 分析正文生成总结
3. 在确认弹窗中编辑摘要、关键事件、伏笔等
4. 保存总结后自动生成上下文记录
5. 章节状态变为「已总结」

## 11. 质量检查

1. 选择已有正文的章节
2. 点击右侧「检查」按钮
3. 点击「开始质量检查」
4. 查看评分、摘要和问题列表
5. 对问题标记「已处理」

## 12. 正文润色

1. 点击右侧「润色」按钮
2. 选择润色模式（如增强描写、减少废话等）
3. 点击「开始润色」
4. 润色结果保存为新草稿，不会覆盖原文
5. 在草稿历史中载入润色稿

## 13. 导出作品

1. 在作品详情页底部找到「导出作品」卡片
2. 点击「导出整本 TXT」或「导出整本 Markdown」
3. 文件会自动下载到浏览器默认下载目录
4. 仅导出已采用的章节正文

## 14. 下一章创作

1. 创建下一章并进入写作工作台
2. AI 生成面板会显示已加载前文上下文数量
3. 正文生成时会自动包含前文摘要、角色状态和伏笔
4. 继续「生成 → 编辑 → 采用 → 总结」循环
