# AI Novel Studio 用户指南

## 1. 创建作品

1. 打开「小说作品」，点击「新建作品」
2. 填写作品名称（必填）、题材、简介
3. 点击确认创建

新建作品、分卷、章节和风格方案等表单会以居中、限宽的弹窗显示。窗口较矮或表单较长时，可在弹窗内部滚动到提交或取消按钮；浅色与深色主题都会保留清晰的表单底色。

## 2. 填写世界背景

在作品详情页：

1. 点击「世界背景」卡片的编辑按钮
2. 输入大致世界观描述，不需要一次性写完
3. 后续 AI 会根据这些内容辅助整理结构化设定

## 3. 设定规则体系

1. 点击「规则体系」卡片的新增规则
2. 填写规则标题和内容（如魔法系统、科技设定、战斗规则）
3. 可添加多条规则，正文生成时 AI 必须遵守

## 4. 设定主角

1. 点击「主角设定」卡片的编辑
2. 填写主角姓名、性格、目标
3. 填写特殊能力与能力限制
4. 填写禁止行为（AI 生成时不会让主角做出这些行为）

## 5. 创建分卷与章节

1. 点击「大纲与章节管理」的新建分卷
2. 填写分卷标题和目标
3. 点击分卷下的新建章节
4. 填写章节标题、大纲和目标字数

## 6. 配置 AI

1. 打开设置中心
2. 使用 Mock 模式进行无 API Key 测试
3. 或关闭 Mock 模式，填写 API Base URL、API Key、模型名称

## 7. 使用 Mock 模式

Mock 模式可以让你在不消耗 API 额度的情况下测试完整工作流：

- AI 正文生成：返回模拟章节正文
- 角色生成：返回预设候选角色
- 事件建议：返回建议事件
- 章节总结：生成模拟总结
- 质量检查：返回模拟问题报告
- 正文润色：返回简单润色版本

## 8. 生成章节正文

1. 在设置中心配置模型（或先用 Mock 模式）
2. 打开默认首页「创作工作台」，选择小说项目
3. 在任务顶部选择目标章节；没有章节时先到「小说作品」创建分卷和章节
4. 发送「生成下一章」或点击快捷模板
5. 等待写章管线完成，对话中会出现候选产物卡片
   - 桌面端使用真实 API 模型时（v3.7.0 起），写章由模型自主完成：运行日志会依次显示它读取作品设定、章纲、人物状态与记忆，再提交一份候选正文；候选正文只供审阅，不会直接写入正式正文。字数明显偏离章节目标、越权调用工具或作用域不符的候选会被拒收并显示失败原因，可点击「重试」
   - Mock 模式与本地模型走确定性写章管线，流程与卡片显示相同
   - 如需回到确定性写章管线，可在浏览器开发者工具中执行 `localStorage.setItem('ai_novel_studio_writing_subagent_dsh', '0')`
6. 确认进入审阅后，在写作工作台修改并保存

## 9. 保存草稿与确认采用

1. 工作台生成的是候选，不会直接写成正式正文
2. 在写作工作台可以直接修改正文
3. 点击「保存草稿」保存当前版本
4. 点击右侧工具栏的「采用」，确认当前草稿为正式正文
5. 已采用的正文会更新章节字数，并写入长期 Memory 供后续检索

## 10. 生成章节总结

1. 确认采用草稿后，点击写作工作台右侧的「总结」
2. 点击「生成章节上下文」，AI 分析已采用正文
3. 检查生成结果与一致性校验
4. 点击「确认保存」生成上下文记录
5. 章节状态变为「已总结」

## 11. 质量检查

1. 在创作工作台选择已有正文的目标章节
2. 发送「检查当前章节质量」
3. 等待对话中的质量报告候选产物
4. 查看摘要、评分与问题列表
5. 根据报告继续提出修改要求，或返回写作工作台人工编辑

## 12. 正文润色

1. 在创作工作台选择目标章节
2. 发送润色要求，例如「增强描写」或「减少废话」
3. 润色结果在对话中作为候选产物出现，不会覆盖正式正文
4. 确认候选进入写作工作台审阅
5. 修改并保存后，再显式点击「采用」更新正式正文

## 13. 导出作品

1. 在作品详情页底部找到「导出作品」卡片
2. 点击「导出整本 TXT」或「导出整本 Markdown」
3. 文件会自动下载到浏览器默认下载目录
4. 仅导出已采用的章节正文

## 14. 下一章创作

1. 在创作工作台选择小说与任务，发送“生成下一章”或“继续写”。
2. 可提供完整章节要求；记忆检索会使用单独的有界查询，不将检索长度限制强加给原始创作指令。
3. 在上下文回执检查持续约束的纳入、替代和预算遗漏；有遗漏或冲突时先明确调整要求，不把回执理解为全部约束均已纳入。
4. 语义一致性提醒需要人工复核；合理相似动作和不同事件时间不会仅凭关键词自动重写。正文缺失、泄漏或持久化完整性等硬错误仍阻止发布候选。
5. 确认候选进入写作工作台，显式编辑、保存、采用，再确认总结，继续下一章。

## 15. 查找与恢复历史任务

任务目录按页读取，可点击“加载更多任务”；搜索同时匹配任务标题和小说名称，并在完整持久目录中查询。“当前/归档”筛选在分页前执行，归档任务不会挤掉当前列表里的待处理任务。重新打开应用时，最近选中的有效任务即使不在第一页也会按 ID 恢复。搜索结果更新和分页加载失败会原位提示，可重试，不代表任务已被删除。

## 16. 审阅和修订结构化候选

1. 人物、事件、设定、大纲与章节总结卡片展示的是原始候选。“已审阅”只标记阅读进度，不表示只应用勾选项。
2. 点击“填写修订意见”，填写建议标题、建议摘要或补充要求；原始标题和摘要不会被这些意见替换。
3. 填写意见后，点击卡片底部唯一的“带出全部意见（数量）”。本卡全部已填意见会追加到原任务输入框，已有未发送内容仍保留；没有意见时仍可点击“要求修改”准备修订目标。检查合并后的要求，再主动发送；此时并未修改正式作品。
4. 等待新候选并重新审阅。桌面端“应用到作品”处理的是整份原始候选，仍须通过既有作用域、来源、基线与原子事务校验；本地审阅标记与意见不会改变此次应用范围。浏览器开发预览不能替代桌面正式应用。
5. 修订意见仅在本次应用会话内临时保留，切换任务或页面后可返回同一候选继续填写；退出应用后清除，候选身份或内容失效后不挪用旧意见。若决定成功但刷新失败，已带出的意见仍保留在输入框中，可重新打开任务检查状态，不要据此认定决定未记录。

## 17. 长目标、定位与通知

- 创作工作台输入框会随目标增长，在有限高度内滚动。点击模板时，已有目标会先询问“追加”或“替换”；替换后可以撤销。中文输入法仍在组合/选词时按 Enter，不会误发送或误创建。
- 任务目录搜索会在短暂合并后更新，并在更新期间保留上一组结果；章节目录和任务目标章节支持按章号或标题查找，也可返回当前章。大目录仍采用有界窗口，不会一次渲染全部章节。
- 保存、采用、加载失败和恢复快照是不同状态。关键错误会保留在原位置并提供重试；普通通知可在悬停或键盘阅读时暂停计时，重要错误需主动关闭。
- 新建作品、卷章、导入、风格方案和恢复提示均为可键盘操作的模态窗口：打开后进入窗口、Tab 不穿透背景、Escape/取消按当前忙态处理，并在关闭后返回触发位置。

## 18. 专注章节审阅

写作工作台默认使用紧凑全局导航，点击“专注正文”可隐藏章节目录，再点“显示章节目录”恢复。正文保持阅读字号，章节大纲与目标、草稿来源信息按需展开。保存草稿与采用正式正文分别显示状态；遇到错误可在原位重试，重试采用仍需要重新确认。关闭非模态右侧面板后，焦点返回原触发处或正文，保留选区与阅读位置。
