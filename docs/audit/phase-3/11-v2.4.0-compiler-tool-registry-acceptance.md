## 5. 真实 API

本版修改 Prompt 和 Provider messages 编译路径，按用户约束只执行一次最大 8-token 连接测试。正式 v2.4.0 窗口读取本机已保存的 OpenAI-compatible 配置，Mock 关闭；Provider 返回空内容，结果为：

```text
Task scope/status       = system / failed
expected Artifact       = generic_text@1
Attempt count/status    = 1 / failed
error                   = AI_PROVIDER_MALFORMED_RESPONSE, retryable=false
Input/Context/Constraint Snapshot schema = 2 / 2 / 2
Context sources/tokens  = 0 / 0
Provider maxTokens      = 8
allowedTools            = []
Artifact count          = 0
```

requestBodyHash 复算一致，compilationHash 为 64 位；Prompt hash 与 Registry hash 等于冻结值。对本次 Task、Attempt、三 Snapshot 及其大文本进行只读扫描，`apiKey`、Authorization、Bearer、配置 Base URL 与 `sk-` 均未命中。

该真实 API 验收结论为**未通过**，原因是 Provider 返回空内容；没有重试，也没有用 Mock 成功改写结论。编译、持久化和失败关闭路径按设计通过。
