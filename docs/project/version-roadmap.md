# 版本路线图

> 当前版本：v1.7.10  
> 完整历史参见根目录 [../version-roadmap.md](../version-roadmap.md)。

---

## 当前阶段：v1.7.x 应用化优化

```text
v1.7.6  阶段性整理、文档体系重整与 EXE 验证 ✅
v1.7.7  桌面端窗口大小控制、响应式 UI 与 2K 适配 ✅
v1.7.8  导出文件位置选择与导出体验优化 ✅
v1.7.9  设定库 AI 推演基础版 ✅
v1.7.10 候选设定采纳与测试补齐 ✅
```

本阶段目标是把已有桌面应用体验收束到可持续迭代状态：文档清晰、窗口规格稳定、导出体验完整、AI 候选能力遵守“用户确认后才写入正式数据”的规则。

---

## 下一阶段：v1.8.0+ 大纲生成

```text
v1.8.0  分卷大纲生成
v1.9.0  章节大纲生成
```

v1.8.0+ 才进入大纲生成能力。本轮 v1.7.6～v1.7.10 不实现分卷大纲生成或章节大纲生成。

---

```text
v2.0.0  正文初稿生成基础闭环

```
