# UI 优化实施与验收清单

本任务为非版本任务，基于 v3.6.2 当前工作树。用户要求完整实现当前 UI 分析列出的六个方向及后续打磨项；不能将单个批次完成等同于整个目标完成。

## 边界与验证顺序

- 保留用户和并行任务已有改动，不提交、推送、打 tag 或发布。
- 不更换 Tauri/React 技术栈、不增加依赖、不改变数据库、候选应用白名单、授权、CAS 或事务契约，不调用真实模型或使用正式用户库。
- 系统强调色继续保留，补全明暗主题配套与对比度；候选审阅意见只在当前应用会话临时保留，不新增跨重启保存。
- 按用户最新要求，全部功能实现之前，不运行 Windows 桌面 E2E、完整 Rust、覆盖率、lint、构建、文档/版本同步或安装包构建。过程中只做源码复核和直接相关的局部动态回归。
- 所有实现完成后才统一执行适用门禁；真实桌面、浏览器、Mock 与单测证据分别记录，不沿用历史通过数字。
